# Catálogo

Todo lo que PanaClaw vende, en prosa. **Esta carpeta no es la fuente de las
cifras** — la fuente es [`datos/precios.json`](../datos/precios.json). Aquí se
explica qué es cada cosa, para quién es y dónde termina.

Si un archivo de aquí y `precios.json` se contradicen, manda el JSON y el archivo
está mal. `node herramientas/verificar.mjs` lo detecta.

## El orden importa

El índice está en orden de **recorrido de compra**, no de catálogo interno:
primero lo que trae a la gente (una web), después lo que se le suma, y al final
lo que solo le sirve a quien ya tiene sitio.

Una campaña que presenta los seis productos a la vez, con el mismo peso, no
vende ninguno. Elige el momento del cliente
([`adn/04-audiencia.md`](../adn/04-audiencia.md)) y entra por el producto de ese
momento.

## Lo que toda ficha de producto debe llevar

Cuando produzcas una descripción de producto —para un anuncio, una propuesta, una
respuesta de WhatsApp— llevan **las cinco o ninguna**:

1. **Para quién es**, en forma de situación
2. **Qué hace**, en el idioma del cliente
3. **Cuánto cuesta**, con su rango completo si lo tiene
4. **Cómo se cobra** — pago único, mensual, 50/50, adelantado
5. **Qué NO incluye**

Un precio suelto es la mitad de la información, y la mitad que falta es siempre
la cara.
